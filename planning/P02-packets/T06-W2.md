## Model rules (request §5.1)
- Fields: `pub`, named exactly as the schema properties, in schema order. Root structs `XxxFile` start with `schema_version: SchemaVersion` and `store_type: <Xxx>StoreType` (markers in `store/mod.rs`; `ReportFile` uses `ReportStoreType`, `LogFile` `LogStoreType`, `SuppressionFile` `SuppressionsStoreType`, `RagIndexFile` `RagIndexStoreType`, `ConversationFile` `ConversationsStoreType`).
- Derives: `Debug, Clone, PartialEq, Serialize, Deserialize`, plus `Eq` where all fields allow it; `#[serde(deny_unknown_fields)]`. No `#[serde(default)]`; no renames except Rust keywords (`r#type`) and enum values snake_case cannot produce (and the PascalCase `EventType` names).
- Field types: uuid → domain ID type; Timestamp → `UtcTimestamp`; closed enums as above; `const false` → `ConstFalse`, `const true` → `provider::ConstTrue`; integers → `u32`/`u64` per bound; nullable → `Option<T>`, always serialised as `null` (never skipped); arrays → `Vec`; maps → `BTreeMap`.
- Plain strings follow Appendix A: N → the named newtype; E → the named enum; S → `SanitisedText`; R → `RedactedText` with `#[serde(deserialize_with = "crate::text::store_read::redacted")]` (or `redacted_opt` / `redacted_vec` / `redacted_map`). Every R field must go through these helpers; none may deserialise `RedactedText` another way.
- Bare `String`/`&str`/`Cow`/`Box<str>`/`serde_json::Value` field types are forbidden (static check). If a schema property is an open object/any type, STOP and report it rather than using `Value`.
- Decode errors must never echo input (use the existing no-echo helpers; see D02 in `values.rs`/`mod.rs`).
- Report every schema constraint you do not enforce at the typed layer (e.g. `minItems`, `uniqueItems`, numeric bounds, `if/then`, cross-field rules) — schema validation (T08) and semantic rules (T09) cover them later.
