## Model rules (request §5.1)
- Fields: `pub`, named exactly as the schema properties, in schema order.
- Derives: `Debug, Clone, PartialEq, Serialize, Deserialize`, plus `Eq` where possible; `#[serde(deny_unknown_fields)]`. No `#[serde(default)]`, and no renames except for Rust keywords.
- Field types:
  - `format: uuid` → the matching `domain::ids` type (missing type → STOP and report);
  - `Timestamp` → `UtcTimestamp`;
  - closed enums → existing domain enums only where the value set is identical (check it); otherwise a new `#[serde(rename_all = "snake_case")]` enum, with explicit `rename` where snake_case does not reproduce a schema value;
  - `const false` → `domain::store::ConstFalse`;
  - integers → `u32`/`u64`;
  - nullable → `Option<T>`, always serialised (as `null`);
  - arrays → `Vec`.
- Plain-string properties follow their Appendix A class: N → the named newtype; E → the named enum; S → `SanitisedText`. None of your defs should need R (if one does, STOP).
- Bare `String`/`&str`/`Cow`/`Box<str>`/`serde_json::Value` field types are forbidden (enforced by a static check).
- Report every schema constraint you do not enforce at the typed layer.
