- **open:** lock, then reconciliation (request §6.5, wave-1a §6): remove only leftover temp files matching `.<known store name or validated report name>[.prev].tmp-<16 hex>` in the root, `rag/` and `backup/` (regular-file check before each removal; count them); runs in `queued`/`awaiting_approval`/`running`/`cancelling` → `interrupted` with `finished_at` = reconciliation time (written through the replace protocol); pending approvals untouched (counted); manifests without report file and report files without manifest reported only; malformed/foreign roots reported in `malformed_roots` and **blocked** (writes refused with `StoreError::Malformed(kind)`) — never rotated into `.prev` (D02-9), never overwritten.
- **replace:** blocked/halted checks, validate, `atomic::write_replace(..., keep_previous = true)`.
- **write_report:** validate the report as `AnyStore::Report`; stem = `report_stem(report.generated_at, slug, report.run_id)`; `atomic::write_new` to `backup/<stem>.json` (`ReportNameCollision` on an existing name, never overwrite); `json_digest` = SHA-256 (lowercase hex) of the exact bytes written; then append the `ReportManifest` (`json_written = true`, `md_written = false`, `pdf_written = false`, `md_path`/`pdf_path` reserved as `backup/<stem>.md`/`.pdf` if the schema requires a value, else per schema) to `log.json` through `replace`, and return it. If the log update fails, the report file stays (reconciliation reports it as without manifest); state this in rustdoc.
- **restore_previous:** validate `<name>.prev` first (invalid/missing ⇒ error, nothing changed); move the current file (if any) into `quarantine/<name>.<YYYYMMDDTHHMMSSZ>` **without overwriting** (hard link then remove, or an equivalent no-overwrite step; collision ⇒ error); restore `.prev` content through the replace protocol; unblock the root.
- **report_stem:** `YYYYMMDDTHHMMSSZ_<slug>_<run-id>` from UTC seconds; total length within `paths::MAX_REPORT_NAME_BYTES` with the longest extension.
