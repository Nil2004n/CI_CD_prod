## Implement (tests only; no production change)
End-to-end adversarial scenarios through the public API (`ApprovalService` over a temp data dir, `evaluate`, `NormalisedDestination::parse`, `child_env`, `SessionCredentialStore`/`read_key`), grouped:
1. **Grant abuse** — for one approved grant, each single change must not authorise: stale workflow revision; changed destination (host, port, scheme, path); lookalike hosts (`api.example.com.` vs `api.example.com` handled per C6, `api-example.com`, `example.com.evil.test`, mixed case, `xn--` label, Unicode homoglyph, IPv4 shortcut forms, `[::1]`); extra/removed repo; extra data category; changed argument value (fingerprint); other run for a run grant; other capability.
2. **Lifecycle abuse** — expired (`expires_at` = now, now−1 s), consumed once-grant reused, denied (R7) and identical request, revoked, pending-only (R8), cancelled; workflow-scope grant after `expire_run`; once-grant under two near-simultaneous `authorise` calls in sequence on the same store (second must not authorise).
3. **Refusals** — raw-secret category under every grant lifetime; deferred capabilities; `model_transmission` without inference scope / with mismatched scope; wildcard (`*`) and empty destinations; argument-name injection (`../`, NUL, control characters, 65-byte names, duplicates).
4. **Seeded-key sweep (application level)** — seed a synthetic key (`pwt-test-FAKE-…`) into: the session credential store, argument values, a host env under innocent and key-like names, a `ToolDirs` path; run request/resolve/authorise/revoke/expire and `child_env` builds; then assert the key bytes appear in no file under the data dir (walk all files), in no `Debug` output of any public type you touched, and in no child env preview or value.
5. **Store tampering** — a hand-edited `approvals.json` that marks a pending request `approved` without `decided_at`/actor, or a once-grant with `consumed=false` after consumption: the store must refuse or the evaluator must not authorise (whichever the accepted design says; read the semantic rules before asserting).
